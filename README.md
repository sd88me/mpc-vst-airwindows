# Airwindows for MPC and Force

Chris Johnson's [Airwindows](https://www.airwindows.com) effects as native plugins for Akai MPC OS standalone devices
(MPC Live, One, X, Key, and Force), with their own touchscreen skins, Q-Link control and a built-in manual.

The effects come from [airwin2rack](https://github.com/baconpaul/airwin2rack) (MIT), so this collection can be updated
whenever new Airwindows plugins appear. Airwindows is by Chris Johnson, released under the MIT licence.

## The collections approach

There are over 500 Airwindows effects. Putting each in the MPC plugin list would bury everything else, so instead there is
**one plugin per Airwindows category**: AW Reverb, AW Tape, AW Filter and so on. Each plugin holds every effect (model)
in its category.

- **Pick a model** with the `<` `>` buttons beside the model name, or from the PRESET menu. Every model is also a preset
  with its own default settings, and each model remembers its settings while you browse.
- **One panel for each model.** Only that model's controls appear, on a console-style panel. Knob caps are coloured by role
  (red gain and drive, blue time and frequency, green tone, white mix). Q-Link badges show which knob number controls what.
- **Pages.** A model with up to 14 controls fits one page. The big channel-strip models (ConsoleX, ConsoleH) have far more,
  so they live in **AW Console Strips**, which has four real pages grouped by section (filter and tone, EQ, compressors, gates).
- **A MANUAL tab in every plugin.** For many models the page opens with a short summary (what it is, how it sounds, what to
  use it for, and one line per control), followed by Chris Johnson's original notes. Where no summary exists yet the original
  text and a short control list are shown.
- **Floating point audio** straight from the host.
- **Same look on every device**: graphite panels with a walnut frame, drawn for this project.

## Installing

Releases will carry a zip per plugin with an installer. Until then, copy a built plugin to the device:

1. In the device's `Synths` folder (`/sdcard/Synths` on a Force, `/nvme/Synths` on a Live III), put the plugin folder
   `Airwindows - VST - AW <Category>/` (the `.so`, `Plugin Skins/`, `version.xml`) and the shared `AW Skin/` folder next to it.
2. Register the plugin in `MPC.settings` (see `docs/DEVELOPING.md`), then restart MPC.

The Force and older MPCs use the `armv7` build; the Live III and other Gen 2 devices use the `aarch64` build.

## Updating from Airwindows

New Airwindows plugins arrive through airwin2rack. `tools/vendor_airwin2rack.sh` pulls the latest source and manuals,
`tools/gen_categories.py` adds the new models to their category (existing parameter positions never move), and the affected
plugin is rebuilt. The current source is recorded in `vendor/VENDORED.md`.

## Building and contributing

Everything about building, the skin artwork pipeline, the device quirks we found and the release plan is in
[docs/DEVELOPING.md](docs/DEVELOPING.md). Build tools come from [mpc-vst-plugins](https://github.com/sd88me/mpc-vst-plugins).
The manual summaries live in `docs/summaries/<Category>.json`, one entry per model, and are written by hand from the original
manual; corrections are welcome.
